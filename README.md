# Prompt — Teleprompter

Teleprompter web app pensata per iPhone. Incolla il testo, tocca Avvia, leggi.

- **Tocca** lo schermo per avviare / fermare
- **Trascina** per scorrere a mano, **pizzica** per ingrandire il testo
- Velocità, dimensione, interlinea, margini, linea di lettura, allineamento, testo specchiato
- Schermo sempre acceso durante la lettura, funziona offline
- Su iPhone: Safari → Condividi → **Aggiungi alla schermata Home** per lo schermo intero

Un solo file statico (`index.html`), nessuna dipendenza.
